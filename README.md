### 👋 About me

- 🏢 Senior Software Engineer at **Himalayan Everest Insurance** (since Jan 2025). Before that: EKbana, NBIT, CloudFactory.
- 🧱 I look after an insurance platform of **50 .NET projects** running as **28 Kubernetes workloads**: accounting, claims, reinsurance and reporting.
- 🚀 Currently leading its move from end-of-life .NET Core 2.2 / 3.1 / 5 to **.NET 10**.
- ✍️ I write about .NET, reverse proxies and running services in production on [Hashnode](https://ijanggmu.hashnode.dev).
